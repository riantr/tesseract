写入

键和值都不能为空；位置留空时写入插入光标当前所在格，写完光标自动前进一格。 「删除 DELETE」只删位置指定的那一格；数位选「无」会清掉该格的数位。

数位

对选中格落子。共享同一条轴向直线的两格不能带同一个数位——冲突会返回 SUDOKU_CONFLICT。空格会先补上键 cell_N。

整套操作

两个红色按钮都会先清空整个点阵。「示例数据巡演」的第一条语句就是 DELETE FROM tesseract;，所以它无法保留现有数据。
